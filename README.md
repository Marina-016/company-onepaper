# 公司一页纸 Skill v1.2.3

## 版本状态

**规则优化版（Rule Optimization）**——仅优化 Skill 文档、模板和规则，未做 Pipeline 开发或大规模回归测试。

基于 v1.2.1 完整复制，在 Skill 规则层面解决真实报告中发现的 8 类问题。

## v1.2.3 新增规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | 章节编号强制检查 | H2 与模板一致，H3 继承父编号；严禁父子编号不一致 |
| 2 | 6 级数据获取优先级 | 结构化接口→Materials V2→研报全文→研报图表→公告/纪要→公开来源；严禁第一级无数据即放弃 |
| 3 | 稀疏行列自动处理 | 行≤1有效→删行，列≤1有效→删列，不足2维度→删表；纯定性表豁免 |
| 4 | 正文行内引用闭环 | 7 类关键内容必须有行内 `[N]`；双向闭环检查 |
| 5 | 参考资料精确格式 | `[N]`来源类型 \| 日期 \| ID：值 \| 机构 \| 标题 \| API：值；序号后无空格 |
| 6 | 参考资料覆盖规则 | 核心维度均有来源，不设机械数量；不加入未使用资料 |
| 7 | 派生测算完整标注 | "内部测算"+基础数据+公式+单位+假设；无法复核→删除数字留定性 |
| 8 | 特殊行业适配 | 保险（NBV/EV/P-EV）/银行/科技/周期/REITs/生物医药指标体系；严禁套用不适用指标 |
| — | 12 项输出前自检清单 | 任一项不满足不得输出最终报告 |
