# 质量检查

交付前逐项检查：

- 是否已生成报告文件，而不是只在对话里输出正文。
- 是否默认生成 Markdown 和 Word（DOCX）两个版本，且除用户指定外直接放在当前工作目录。
- 是否没有把素材 JSON、HTML、TXT、渲染图片等临时文件作为最终交付物保留在工作目录。
- 是否明确市场、ticker、生成日期、价格/市值口径和数据日期。
- 是否第 1 章为 `关键要点`，且没有尾部 `Key Takeaways` / `Investment Takeaways` 章节。
- 近况跟踪是否放在第二节，且聚焦过去 1-3 个月事实。
- 研报、会议纪要、公告是否读取到详情/全文；是否避免只用列表摘要写正文。
- 是否优先使用 `getMaterialsV2` 检索研报、纪要、市场点评、公众号相关片段，并基于片段 ID 只补拉关键全文/详情。
- `getMaterialsV2` 是否至少覆盖近况/催化、投资逻辑、业务财务、产销生态、估值分歧、市场关注六类 query。
- 若正文引用了公开新闻，是否为近 1-3 个月关键事件补充，且来源为公司/交易所/监管/权威财经媒体；若平台不能联网，是否没有编造公开新闻。
- 若正文引用公开 URL，该来源是否已写入 materials JSON 的 `external_sources`，并包含标题、日期、发布方、URL 和正文快照。
- 所有关键数据和判断是否有 `[N]` 引用。
- 正文出现的每个 `[N]` 是否都能在参考资料章节找到定义；是否不存在正文未定义引用。
- 参考资料中的每个 `[N]` 是否都能回溯到 materials JSON 的真实来源实体或结构化接口。
- 参考资料每条 `[N]` 的标题（title）是否与 JSON 原始元数据**逐字一致**，没有被截断、改写、或去掉前缀/后缀/标签（含 `【】` 包裹的标签）。
- 参考资料每条 `[N]` 的机构（organization/orgName）是否与 JSON 原始元数据**逐字一致**，没有被替换为来源类型（如把 `cwamcc` 写成"机构研报"、"微信"等）。
- 来源为预测、目标价、指引或情景假设的数据，正文是否保留"预计/预测/指引/假设/基于[N]推算"等属性，而不是写成已发生事实。
- 是否没有占位符、空表格、虚构数据、无来源的市场份额/客户/预测。
- 是否没有出现“未披露”“未列”“未提供”“无数据”“N/A”等填空式措辞；缺数据处是否改成披露口径、替代指标或直接删去对应表格字段。
- 港股财务是否优先使用 `getHkFdmtIsPit`、`getHkFdmtBsPit`、`getHkFdmtCfPit` 三个 PIT 报表接口；美股财务是否说明 GAAP/non-GAAP/segment/guidance 口径。
- v1.2.0：美股/ADR 缺少 HK PIT 三表时，正式评测是否记录为 `skipped_with_reason` / `N/A`，且没有计入财务检查通过数。
- v1.2.0：美股/ADR 是否清楚区分财年和自然年，并在人民币、美元、ADS、普通股等单位之间保持表头和正文一致。
- 资本开支是否区分公司披露 CapEx、研报口径 CapEx、现金流量表"购建长期资产支付现金"，没有把不同口径混写成同一个指标。
- ROE 是否使用常规定义或接口直接披露值；若使用替代算法，是否已改名为具体算法而不是继续写 ROE。
- 风险提示是否使用最新报告期数据；若使用旧期数据，是否解释原因。
- 是否没有调用停用接口：`research_sec_foredata`、`stock_evaluationAnalysis`、`diagnosis_valuation_rank`、`Stock_OnePage`、`market_snapshot`、`market_HK`。
- 单位是否一致：人民币、港元、美元不可混用；亿元/百万/十亿要统一换算并注明。
- 估值是否写清方法和口径：PE、EV/EBITDA、P/S、SOTP、DCF 或同业比较。
- 市场分歧是否具体，不只是风险提示改写。
- A/H 映射是否给出可比业务，而不是只列股票名。
- 行业对比/AH 映射中每个可比公司行是否至少有一个来源；市值是否注明日期并标注引用，私有公司估值是否避免写成确定事实。
- 正文中是否避免频繁出现具体券商名；参考资料可保留真实来源。
- 美股是否只写“市场关注”，没有输出“调研问题/调研大纲”；港股是否按 3-4 个议题、每题 2-3 个可量化问题输出调研大纲。
- 若正文观点不是来自具体机构材料，是否用“解读：”承接，而不是写“买方认为/机构认为”。
- 参考资料是否严格使用简洁格式：公开来源直接列类型、日期、发布方、标题、URL；Datayes 来源只保留 `ID：` 和 `API：` 标签。
- §11.4 敏感性数字是否全部来自来源直接给出；自行推导的是否标注"内部测算"并给出公式；无来源复核的是否已删除。
- FY/CY/季度/自然年标签是否保留原始口径；是否没有出现 FY2027 与 CY2027 混用、FY2026后续季度与FY2027互替。
- `errors` 中的接口失败是否没有污染报告正文。

### v1.2.3 新增检查项

- [ ] **章节编号**：H2 与模板一致，H3 继承父编号，同级连续无重复，无 `## 3` 下出现 `### 2.1`
- [ ] **空表/稀疏行列**：全部搜索完成后执行稀疏处理（行≤1 有效→删行，列≤1 有效→删列，不足2维度→删表），无 `—`/`N/A`/空格/待补充；纯定性表除外
- [ ] **数据优先级**：缺失数据已按 结构化接口→Materials V2→研报全文→研报图表→公告/纪要→公开来源 逐级尝试，非第一级无数据即放弃
- [ ] **行内引用完整**：核心结论/财务/经营/行业/预测/估值/催化剂/风险中的具体事实均附 `[N]`，非仅在末尾列参考资料
- [ ] **参考资料格式**：`[N]`来源类型 | 日期 | ID：值 | 机构 | 标题 | API：值，`[N]` 后无空格，字段顺序固定
- [ ] **双向闭环**：正文引用 ⊆ 参考资料 ⊇ 正文引用（无孤儿引用、无死引用、无 materials JSON 不存在的 ID）
- [ ] **无 SRC-X 残留**：所有内部编号已替换为最终 `[N]` 格式
- [ ] **Actual/Forecast/Guidance 区分**：预测/指引/情景假设在正文明确标注，未改写为已发生事实
- [ ] **FY/CY/报告期/币种/单位**：准确未混用（尤其美股/ADR：财年≠自然年，人民币≠美元）
- [ ] **派生测算**：有"内部测算"标注 + 基础数据 `[N]` + 完整公式 + 单位 + 核心假设；无法复核则只保留定性判断
- [ ] **特殊行业适配**：保险用 NBV/EV/P- EV/偿付能力，银行用 NIM/不良/P-B，科技用 GMV/MAU/P-S 等；无套用通用指标
- [ ] **参考资料覆盖**：不设机械固定数量但核心维度均有来源；材料充足时交叉验证；不加入正文未使用的无关资料
- [ ] **输出的 md/docx 为最终文件**：无多余临时文件残留
