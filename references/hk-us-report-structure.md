# 报告结构

报告默认中文，控制为"买方一页纸"的密度：结论优先、表格精炼、每节有数据支撑。

**通用规则**：
- **数据精确性**：历史财务数据必须使用接口返回的真实数字，**严禁"约""大约""估计约"等模糊表述**，也严禁定性化代替具体数字（"收入有所增长"→必须"收入增长X%至$XX亿"）
- **机构名称规范**：正文叙述不得出现具体券商/机构名称，用"头部机构""主流机构"代替；**例外：机构目标价汇总表（§11.1）中直接展示机构真实名称**
- **序号规范**：正文列举项使用 `1）2）` 或 `•`，**严禁 `1、2、3` 中文序号**

**引用标注位置规则**：
- `[N]` 必须紧跟在**具体数值**（数字、百分比、金额、倍数等）后面，如 `675[5]`、`+12.3%[1]`
- **严禁**将引用挂在以下非数值列：机构名称、指标名称、行标题、评级标签、假设描述
- 简记：**引用只跟数字，不跟名称或描述**
- **引用完整性硬门槛**：正文引用集合必须全部出现在第13章参考资料中；若正文出现未定义编号，报告不得交付。
- **来源实体硬门槛**：每个参考资料编号必须能回溯到 materials JSON 的来源实体或结构化接口；禁止新增不存在的 `[N]`。

**事实属性规则**：
- `Actual`、`Forecast`、`Guidance`、`Estimate` 必须分开写。来源文字为"预计/预期/有望/目标价/预测/或将"时，正文必须保留这些限定词。
- 禁止把预测写成已发生事实，例如来源只写"预计推出"，正文不得改写为"已发布/已上线/已实现"。

**缺数据时的处理规则**：
- 若某列数据在 Datayes API + 研报中均未披露/未获取（如净利润为 `—`），且运行环境与用户授权允许公开检索，可用公开来源补充并写入 `external_sources`
- 若不能公开检索或仍未找到：将该列从表格中**直接隐藏/移除**，表格只保留有数据的列
- 正文中若某数据点确实无法获取，使用具体说明代替（如"FY2025 净利润未在财报中单独列示"），**严禁出现 `—`、`N/A`、`未披露` 等空白填充**

**表格格式铁则**：
- 🚨 每张表格列数上限：普通数据表 ≤ 8 列，同业对比表 ≤ 10 列；超出必须精简合并
- 🚨 **公司+代码合并**：任何表格中涉及公司名和代码的，**必须合并为一列**，格式 `公司名（代码）`（如 `腾讯控股（00700.HK）`），**严禁**将"公司"和"代码"分两列
- 🚨 参考资料章节**必须用纯文本列表**，**严禁使用 Markdown 表格**
- 表格对齐符号统一使用 `:--`（左对齐），中间列用 `:--:`（居中）仅限数字列
- **Word 合并规则**：生成 Word 时，所有表格首列中**连续相同**的单元格会自动纵向合并（跳过表头）；若需要合并"指标/类型/情景"等首列，请在 Markdown 中连续重复完全相同的首列文本，不要用空白单元格占位。
- 列标题保持简短（2-6字），把空间留给数据

## 标题

标题按市场区分：

**港股**：
```text
# {公司名}（{ticker}）港股公司一页纸：{一句话结论}
```

**美股**：
```text
# {公司名}（{ticker}）美股公司一页纸：{一句话结论}
```

- **一句话结论**：约20字（最多25字），须在语义完整处自然结尾，**严禁句子中断**，体现最核心驱动力或投资判断

标题下方放一行信息：

```text
市场：{港股/美股} | 行业：{行业} | 当前价格/市值：{价格和市值，注明日期} | 生成日期：{YYYY-MM-DD}
```

## 1 关键要点

用 4-6 条中文结论直接回答：

- 为什么现在值得看？
- 最大上行来自哪里？
- 最大下行来自哪里？
- 下一次需要跟踪什么？
- 市场当前定价的核心分歧是什么？

写法要求：每条必须是投资结论，不是摘要复述；尽量包含可验证指标，并标注来源 `[N]`。

- 一句话说明市场解读。
- 最后一段写主流评级、目标价区间、估值区间或一致预期变化。

## 11 估值与预测

**第 11 章图表分析铁则**：本章每张 Markdown 表格或图表后，必须紧跟一段中文文字分析，长度控制在 20-300 字；分析必须解释表内数据的投资含义、分歧来源或后续验证点，不得只复述表头或泛泛总结。

### 11.1 机构目标价汇总

从研报全文和 Materials V2 中提取各机构给出的目标价和评级，每行对应一个独立来源。

**🚨 引用位置铁则（表内专用）**：
- `[N]` **必须紧跟在目标价数值后面**（如 `675[5]`），**禁止**挂在机构名称列（如 `Wolfe Research[5]` 是错误写法）
- 同理：估值方法、评级、关键假设等描述性列均**不得**附加 `[N]`
- **一个机构在一个日期发布的目标价，只引用编号，不再在机构/评级/假设列重复标注**

错误示例：
```
| Wolfe Research[5] | 675 | ...   ← 错：引用在机构名上
```

正确示例：
```
| Wolfe Research | 675[5] | ...   ← 对：引用紧跟数值
```

模板：
| 机构 | 目标价（{币种}） | 估值方法 | 评级 | 关键假设 |
|:-----|:----------------|:---------|:-----|:---------|
| [机构A] | [目标价][N] | [PE/PS/DCF等] | [买入/增持/中性等] | [一句话] |
| [机构B] | [目标价][N] | [估值方法] | [评级] | [一句话] |

**数据来源**：每行至少标注一处 `[N]`，`[N]` 必须出现在**目标价数值**所在单元格内，不得出现在其他列。（若同一机构同一研报同时给出目标价和盈利预测，可在估值方法列补充参考来源说明，但仍不得在机构名列附加 `[N]`）
- **估值方法列处理规则**：优先从研报摘要提取明确写出的方法；若摘要未直接写出但讨论了估值相关指标（如 ROE 目标、PB 区间、DDM 参数），可从上下文合理推断，并在估值方法前标注"推断："，同时给出推断依据的引用 `[N]`；确实无法判断的填"—"，并在表后说明。
